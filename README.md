Bu projede admin paneli ve websitesi oluşturuldu. 
CRUD operasyonları gerçekleştirildi.
SignalR ile gerçek zamanlı verilerle işlemler yapıldı. Mesajlaşma, bildirim, sepet vb. gerçekleştirildi. 
MSSQL veri tabanıyla ilişki tablolar oluşturuldu.
Rezervasyon işlemlerinde Mail gönderme işlemi yapıldı. TinyCloud ile mail görünümü sağlandı.
QR code oluşturuldu ve QR code decoder ile metne dönüşüm sağlandı. 

Kullanılan teknolojiler:
-Asp.Net Core 8
-Asp.Net Core API
-Entity Framework
-SignalR
-MSSQL
-Swagger
-HTML
-CSS
-Javascript
-Boostrap
-Ajax
-Mail
-QR Code
