Bu projede admin paneli ve websitesi oluşturuldu. <br>
CRUD operasyonları gerçekleştirildi. <br>
SignalR ile gerçek zamanlı verilerle işlemler yapıldı. Mesajlaşma, bildirim, sepet vb. gerçekleştirildi. <br>
MSSQL veri tabanıyla ilişki tablolar oluşturuldu. <br>
Rezervasyon işlemlerinde Mail gönderme işlemi yapıldı. TinyCloud ile mail görünümü sağlandı. <br>
QR code oluşturuldu ve QR code decoder ile metne dönüşüm sağlandı. <br>

Kullanılan teknolojiler: <br>
- Asp.Net Core 8
- Asp.Net Core API
- Entity Framework
- SignalR
- MSSQL
- Swagger
- HTML
- CSS
- Javascript
- Boostrap
- Ajax
- Mail
- QR Code
