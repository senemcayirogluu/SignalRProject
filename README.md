# SignalR Project | SignalR ile Proje


## English Version

### Project Overview  
In this project, an admin panel and website were created.  
CRUD operations were performed.  
Real-time data processing was carried out using SignalR. Messaging, notifications, shopping cart, etc. were implemented.  
Relational tables were created with an MSSQL database.  
Email sending was implemented for reservation transactions. Email viewing was provided using TinyCloud.  
QR codes were generated and converted to text using a QR code decoder.  

### Technologies Used  
- Asp.Net Core 8  
- Asp.Net Core API  
- Entity Framework  
- SignalR  
- MSSQL  
- Swagger  
- HTML  
- CSS  
- Javascript  
- Boostrap  
- Ajax  
- Mail  
- QR Code
